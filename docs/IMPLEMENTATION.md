# TasteIndia implementation plan

Source brief: Android_Intern_Assignment_TasteIndia.pdf, September 2026.

1. Native Kotlin, Compose Material 3 app; API 26–35, Java 17.
2. Retrofit V1 service, complete field normalization, immutable domain models.
3. Authoritative Indian-area base IDs; cached-detail category and first-ingredient intersection.
4. Four concurrent lookups maximum, per-ID deduplication, disk cache, explicit offline fixtures.
5. Separate list and detail ViewModels, ID routes, saved filters and independent scroll state.
6. Persistent favourite snapshots, usable without network.
7. Editorial cream/forest/saffron design, adaptive dark theme, accessible controls and error states.
8. Deterministic tests, build/lint, review guide and honest AI disclosure.

The candidate must review, understand and adapt this AI-assisted implementation before submission.
